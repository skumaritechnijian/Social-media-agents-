# Social Media Agents

Automation workspace for Technijian social video publishing and digital marketing workflows.

## Contents

- `social-media-automation/` - platform posting scripts, shared social post packages, generated captions, YouTube metadata, and thumbnail scripts.
- `technijian-in-automation/` - skills, agents, harnesses, and implementation guide for SEO and digital marketing management workflows.

## Safety

Browser profiles, auth folders, OAuth client secrets, API keys, downloaded videos, and `node_modules/` are intentionally excluded from version control.
