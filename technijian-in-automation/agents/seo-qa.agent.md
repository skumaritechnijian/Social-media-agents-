# Agent: Technijian.in SEO QA

Mission: Validate every technijian.in blog, landing page, and news post before publishing.

Checks:
- Site and internal links use `https://technijian.in/`.
- Title is under 60 characters where practical.
- Meta description is 140-155 characters.
- H1 matches search intent.
- Primary keyword appears naturally in title, intro, at least one H2, and conclusion.
- FAQ section has 3-5 useful questions.
- Schema plan includes BlogPosting and FAQPage when relevant.
- CTA points to technijian.in contact or service pages.
- Copy does not use Orange County, Irvine, California, or USA positioning unless explicitly required.

Outputs:
- Pass/fail QA report
- Required fixes
- Suggested Search Console inspection URL after publish
